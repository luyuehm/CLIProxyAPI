# CPA Usage Keeper Enterprise — 企业功能说明

## 产品定位

CPA Usage Keeper 是 [CLIProxyAPI (CPA)](https://github.com/router-for-me/CLIProxyAPI) 的**用量监控管理面板**，提供 CPA 用量数据的持久化存储、可视化分析和企业级管理功能。Enterprise 版将其打包为一键部署的企业级解决方案。

## 核心功能

### 📊 用量监控

- 实时用量总览（4h / 8h / 12h / 24h / 7d / 30d 时间范围）
- 请求量、成功率、延迟趋势图表
- 按模型 / Provider / API Key 维度分析
- Token 消耗、成本估算、缓存命中率
- RPM/TPM 峰值监控

### 🔔 告警管理

- 基于用量阈值的告警规则配置
- 告警通知渠道（管理面板内通知）
- 告警历史记录和确认管理

### 💰 预算管理

- 按用户/项目/模型的预算设置
- 预算使用百分比实时追踪
- 预算超限告警通知

### 🔒 内容过滤

- 敏感内容过滤规则配置
- 关键词/正则表达式匹配
- 命中统计和日志审计

### 👥 用户管理

- 多用户/多 API Key 管理
- 用户分组和权限控制
- 操作审计日志

### 💳 费用分摊

- 按用户/项目/模型的费用拆分
- 定价倍率配置（用户级别的价格控制）
- 费用报表导出

### 📈 社区排名

- 按综合评分、Token、请求量、缓存命中率等维度排名
- 可选参与社区排名（保护隐私）

### 🛡️ 服务健康检查

- 内置健康检查脚本
- 容器健康状态监控
- 数据同步状态检查

## 企业版特性

| 特性 | 说明 |
|------|------|
| 私有化部署 | 数据不出域，代码在你自己的服务器上运行 |
| 一键部署 | `bash install.sh` 即可完成部署 |
| 跨平台 | 支持 Linux / macOS / Windows（Docker 环境） |
| 数据持久化 | SQLite 数据库 + 自动备份 |
| 登录保护 | 内置密码登录 + Session 管理 |
| 子路径部署 | 支持通过反向代理部署在子路径下 |
| 内置 HTTPS | 可选直接启用 TLS |
| 自动升级 | `update.sh` 一键升级到最新版本 |

## 适用场景

- **企业开发团队** — 需要统一管理多个 AI 模型 API Key 和用量
- **金融 / 医疗行业** — 数据合规要求，不能使用第三方 SaaS
- **教育机构** — 需要为师生提供 AI API 代理和用量管理
- **AI 创业公司** — 需要精细化费用分摊和预算管理
