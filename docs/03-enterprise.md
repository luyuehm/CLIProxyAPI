# AI Gateway Enterprise — 企业版功能

## 产品定位

AI Gateway Enterprise 是一个**私有化部署的 AI 网关产品**，将 CPA（核心路由引擎）和 KEEPER（用量监控平台）整合为可一键部署的企业级解决方案。

## 核心功能

### 🔀 统一路由引擎（CPA）

- 支持 160+ AI 模型提供商（OpenAI / Claude / Gemini / DeepSeek / Qwen 等）
- OpenAI 兼容协议，一行代码切换
- 自动 failover（主 provider 失败时自动切换到备用）
- 冷却机制（错误率过高时自动降级）
- 负载均衡（多 API Key 自动轮询）
- 用量统计（Redis 队列，异步写入，不影响性能）

### 📊 用量监控面板（KEEPER）

- 实时用量总览（4h / 8h / 12h / 24h / 7d / 30d 时间范围）
- 请求量、成功率、延迟趋势图表
- 按模型 / provider / API Key 维度分析
- 配额管理（Claude / Codex / Gemini / Kimi / xAI / Antigravity）
- 定价倍率配置（用户级别的价格控制）
- 服务健康检查

### 🔒 企业级特性

| 特性 | 说明 |
|------|------|
| 私有化部署 | 数据不出域，代码在你自己的服务器上运行 |
| API Key 自持 | 你的 API Key 不经过第三方平台 |
| 授权管理 | License Key 验证，防止未授权使用 |
| 一键部署 | `bash install.sh` 即可完成部署 |
| 跨平台 | 支持 Linux / macOS / 任何 Docker 环境 |

- **企业开发团队** — 需要统一管理多个 AI 模型 API Key

- **教育机构** — 需要为师生提供 AI API 代理
